## Risks Determina tests

Search Behavior Trials focus on:

- relevance loss
- freshness gaps
- ambiguous intent
- typo recovery
- zero-result behavior
- personalization drift
- baseline-vs-candidate ranking changes

## Supported workflows

Search supports native HTTP and schema-mapped HTTP setup, hosted audit and compare workflows, and generated scenario/persona coverage through advanced platform-owned paths.
