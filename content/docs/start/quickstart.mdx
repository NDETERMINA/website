## Before you start

You need a Determina platform API base URL and API token. The quickstart assumes
you are inside the repository for the app or agent you want to review.

<Callout variant="warning" title="Access note">
Hosted workflows require platform access. If you are only checking the package locally, use the Local Package Smoke Test instead.
</Callout>

## Configure the CLI

<CodeBlock language="shell" code={`export DETERMINA_API_BASE_URL=https://api.ndetermina.com
export DETERMINA_API_TOKEN=<token>`} />

<Verify>Authenticated review commands fail before making requests when no token is configured.</Verify>

## Set up this repo

Run setup once from your app or agent repository. Determina detects the repo
shape, writes local defaults, creates a starter review recipe, checks the setup,
and prints one next command.

<CodeBlock language="shell" code={`determina setup`} />

<Verify>Setup should create or reuse `.determina/config.yaml` and a starter recipe under `determina/reviews/`.</Verify>

## Run your first review

Run the starter review recipe. After setup, you can usually omit the recipe path
and run `determina review run`; the explicit path below shows what will run.

<CodeBlock language="shell" code={`determina review run determina/reviews/starter.yaml`} />

Determina attaches review metadata automatically when it is available,
including git commit, branch, timestamp, package version, and deployment target.
The platform uses that metadata to group reviews by commit, branch, and release.

<Callout variant="info" title="What setup handles">
You do not need to create hosted records by hand before the first review. Setup and review run handle the platform bookkeeping for the quickstart path.
</Callout>

## Inspect results

The review command queues hosted work, polls for a terminal state by default,
and prints the run id, decision, and platform URL when the API returns them.

<CodeBlock language="shell" code={`determina runs list --root .determina/runs
determina runs show <run-id-or-path>`} />

You can also use the review-facing aliases:

<CodeBlock language="shell" code={`determina review list --root .determina/runs
determina review show <run-id-or-path>`} />

Use the CLI reference when you need advanced status polling, artifact download,
explicit platform objects, generated test cases, or direct audit/compare commands.
