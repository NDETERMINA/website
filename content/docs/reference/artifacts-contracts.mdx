## Evidence Files

Common evidence files include:

<DataTable
  headings={["File", "Purpose"]}
  rows={[
    ["report.md", "Human-readable review summary."],
    ["results.json", "Structured run result."],
    ["traces.jsonl", "Trace-level interaction detail."],
    ["run_manifest.json", "Workflow metadata, inputs, outputs, and artifact refs."],
    ["regression_report.md", "Compare summary for baseline and candidate."],
    ["generated_coverage_manifest.json", "Test case provenance where generated test case workflows are used."]
  ]}
/>

Agent workflows can add external call event files, external call checks, variant manifests, task/environment pack refs, stress manifests, and advisory helper sidecars when explicitly configured.
